  • Nov 19 The review that invented a bug en español A review of my own work found five real defects and one that did not exist. The sixth is the useful one: a failing command confirmed the story I had already written instead of challenging it.
  • Nov 18 An agent that cannot invent its sources en español Most retrieval demos fall apart the first time the model invents a page number. The fix is not a better model — it is a verifier the model cannot talk its way past.
  • Nov 18 The challenge was closed before we started I had a five-phase plan for a 72-hour challenge before I read the entry window. It had closed 44 days earlier, and the plan was a table of contents rather than a decision.
  • Nov 18 Preflight: the gate that listens Preflight reads what a screen reader actually announces, scores the page by whether someone is blocked, and returns a repair prompt an AI builder can execute. What it does, what it refuses to claim, and why the transcript is the product.
  • Nov 18 What happens during a Preflight scan A URL goes in, a real browser renders the page, axe reads the rules, a virtual screen reader walks the accessibility tree, a score refuses to be green while someone is blocked, and a fix prompt comes out.
  • Nov 17 The Quieter Announcement en español I fixed a screen reader bug by deleting an announcement. React Spectrum's live region was overwriting what VoiceOver already said natively, and no linter could see the collision.
  • Nov 3 The bug jsdom could not see en español A shadcn/ui PR sat for three months while 61 jsdom tests passed. jsdom does not fire scroll events for programmatic scrolls, so it could not see the spacer collapse the fix introduced. Browser tests found that and two more bugs.
  • Oct 22 The dialog description that never arrived Carbon's ComposedModal forwarded a title but no description, so screen readers announced a dialog with no clear purpose. The PR added aria-describedby, and review caught a test that proved only the attribute.
  • Oct 7 Sortable headers are not toggle buttons A sortable Datagrid header announced itself as a toggle button, because aria-pressed competed with aria-sort and won. Removing the attribute let the sort direction reach the user again.
  • Sep 14 Focus after the step changed Pressing Next in CreateFullPage sent focus to the skip link: the helper looked for an inert attribute the component never set. One querySelector for the visible step class fixed it, and a focus assertion that had never existed.
  • Sep 9 Counting items across sections A test-only PR locks in that aria-posinset stays global across menu sections. The first version flattened the fixture, went green and tested nothing; the corrected one renders the real sections.
  • Aug 28 Orchestrating a 10,000-line refactor A 10,000-line macOS app spread across three giant files became a modular structure through four stages kept apart: planning, execution, cross-review by a different model, and verification. The public API never moved.
  • Aug 26 Naming a tree TreeList accepted every BaseProps attribute and dropped it before the DOM, so a headerless tree could not be named. The fix was three precedence rules and a test that asserted on the element carrying the role.
  • Aug 25 When a HoverCard calls itself a dialog A labelled HoverCard trigger described itself with aria-describedby, so screen reader users heard the card's contents as a description instead of learning that a dialog opens. The fix is the popup contract, with two review catches along the way.
  • Aug 24 aria-orientation belongs to the role owner en español A Combobox with grid rendered aria-orientation on role=grid, which does not support it. The attribute moved to the components that assign the role; the keyboard hook kept only the behavior.
  • Aug 24 A breadcrumb that does not rely on color Astryx marked the current breadcrumb item with a slightly darker gray and nothing else, failing WCAG 1.4.1. The fix was one font-weight declaration, and the trade was a few pixels of width.
